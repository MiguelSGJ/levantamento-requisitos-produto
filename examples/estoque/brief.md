# Brief fictício — sistema de estoque

> Exemplo inventado apenas para demonstrar a skill; **não representa um cliente real**.

A pessoa responsável informa:

“Preciso de um sistema web para uma loja pequena registrar produtos,
entradas e saídas do estoque. Quero consultar a quantidade disponível.
Algumas pessoas trabalharão no estoque, mas ainda não decidimos os perfis.
Talvez seja útil gerar relatórios no futuro.”

**Fatos explicitamente informados:**
- O sistema será web.
- Existirão produtos e registros de entrada/saída.
- Deve ser possível consultar quantidade disponível.
- Mais de uma pessoa poderá trabalhar no estoque.

**Não confirmado:**
- Quem pode alterar ou excluir produtos.
- Quais campos são obrigatórios.
- Como será calculado estoque em ajustes e estornos.
- Se o sistema terá controle por unidade/depósito.
- Se haverá autenticação, API externa, inventário ou auditoria.
- Se os relatórios entram na primeira versão.
