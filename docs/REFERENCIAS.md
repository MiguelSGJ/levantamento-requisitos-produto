# Referências técnicas e conceituais

As referências abaixo servem como **apoio para melhorias e revisão crítica** da
skill. Não são certificações, licenças para reproduzir obras protegidas nem
regras de produto obrigatórias. O responsável por cada sistema define o que
é aplicável.

- **ISO/IEC/IEEE 29148:2018 — Requirements engineering:** [catálogo oficial
  ISO](https://www.iso.org/standard/72089.html). Diretrizes para processos de
  engenharia e gestão de requisitos. O texto integral da norma **não é
  redistribuído neste repositório**.
- **SWEBOK Guide v4.0 — Software Requirements:**
  [IEEE Computer Society](https://www.computer.org/education/bodies-of-knowledge/software-engineering/topics).
  Referencial de conhecimento em engenharia de software, incluindo requisitos.
- **Agent Skills:** [especificação](https://agentskills.io/specification).
  Define a estrutura portátil baseada em `SKILL.md` e metadados de ativação.
- **Codex Skills:** [documentação oficial](https://developers.openai.com/codex/skills).
- **Claude Code Skills:** [documentação oficial](https://code.claude.com/docs/en/skills).
- **OWASP ASVS:** [projeto oficial](https://asvs.owasp.org/). Apoia
  requisitos verificáveis de segurança de aplicações, quando aplicável.
- **WCAG 2.2:** [W3C](https://www.w3.org/TR/WCAG22/). Diretrizes de
  acessibilidade web; a versão ou nível exigido por um projeto requer decisão.
- **GitHub Community Profiles:** [documentação oficial](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/about-community-profiles-for-public-repositories).

> Nota: o levantamento real que inspirou a profundidade de cobertura não é
> distribuído aqui. Todo exemplo no repositório deve usar dados fictícios.
