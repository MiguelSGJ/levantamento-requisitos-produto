# Product Requirements Discovery — Agent Skill

An open-source, Portuguese-first agent skill that helps gather, structure,
trace, and verify software product requirements **without making unapproved
product decisions**.

It covers stakeholders, scope, roles and permissions, business rules, entity
fields, workflows and state transitions, API contracts, security,
notifications, auditing, acceptance criteria, and pending decisions.

- **Skill file:** [SKILL.md](SKILL.md)
- **Install:** [docs/INSTALACAO.md](docs/INSTALACAO.md) (Portuguese)
- **Contribute:** [CONTRIBUTING.md](CONTRIBUTING.md)
- **Roadmap:** [docs/ROADMAP.md](docs/ROADMAP.md)
- **License:** [MIT](LICENSE)

The skill works as a folder containing a `SKILL.md` file in both Codex and
Claude Code. Automated tests currently validate files/metadata rather than
LLM behavior; evaluation improvements are planned.

The project is unofficial and not affiliated with OpenAI or Anthropic.
